# ユーザーの好みと判断基準

「明示」はユーザーが直接指示した内容、「推測」は AI の推測。推測はユーザーの確認が取れたら明示へ移す。

## 明示

- 回答は日本語で、簡潔に要点だけ。前置きや挨拶は不要。
- 複雑な判断に迷ったら、自分で決め切らずに次のステップを確認する。
- 出力に過度な装飾を使わず、結論とデータを優先する。
- このリポジトリは自分用の改造として進める（2026-11-07）。
- 開発は「AI Game Development Framework」指示書に沿って、フェーズごとに報告と承認を挟む。
