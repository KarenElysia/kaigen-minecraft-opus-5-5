# 品質基準

## 性能

| 項目 | 基準 |
|---|---|
| フレームレート | デスクトップ 60fps、モバイル 30fps（F3 の統計で確認） |
| メモリ | iOS で動くこと（2GB の予約は不可。ワールドアリーナは実際の上限から計算する） |
| ストリーミング | 移動中にチャンク抜けや長いヒッチが出ない |

## コード

- AGENTS.md のハードルールを守る（libc・malloc・スタック配列・グローバル・printf の禁止、ロックステップ）。
- コメントは制約を述べる 1 行と短い関数説明だけ。
- コンパイル警告とエラーをゼロにしてから完了とする。

## ゲームと見た目

- 操作に即座のフィードバックがある（音、パーティクル、UI の反応）。
- UI はデスクトップとスマホ縦横の両方で読める。
- 画質プリセット LOW〜ULTRA のすべてで破綻がない。
- 定点スクリーンショット（昼・夕方・夜・雨・水中）で変更前後を比較し、意図しない差がない。

## フェーズ完了時の自己評価項目

機能の完成度、コード品質、ビジュアル品質、操作性、パフォーマンス、拡張性、バグの有無。
