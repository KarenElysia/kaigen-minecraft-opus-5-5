# 知見と再発防止策

| 知見 | 再発防止策 | 出典 |
|---|---|---|
| Web ビルドには書き込み可能なファイルシステムがない | 永続化はファイル I/O を前提にしない。ブラウザ側のストレージにはエンジンの対応が必要か先に確認する | cac75d1 |
| iOS は 2GB の仮想メモリを予約できない | 大きなアリーナは実際に必要な上限から計算して確保する | 7f750ad |
| モバイルブラウザではマルチスレッドのビルドが安定しない | モバイルは単一スレッドのビルドを前提に性能を設計する | 9ec5c82 |
| 高 DPI 端末でフル解像度を描くと重い | DPR は 1 に固定し、画質はレンダースケールと TAA アップスケールで調整する | f3f90f3 |
| `.claude/` 配下をローカルの絶対パスへのリンクにすると他の環境で壊れる | 共有が必要な設定は実体をコミットするか、相対リンクにする | 2026-11-07 調査 |
| `hz` リンクが存在しないエンジン版（0.6.4.002）を指しているとビルドが `WcSettings.render_distance: type 'u32' has no definition` で落ちる。型定義の欠落に見えるが、実際はエンジンの src が解決できていないことが原因 | ビルド失敗時はまず `hz` の向き先が実在するかを確認する。`hz` はマシン固有リンクなので、導入済みのエンジン版へ張り替える（2026-11-08 に 0.7.0.001 へ張り替えて `hz/hzbuild` 成功） | 2026-11-08 調査 |
