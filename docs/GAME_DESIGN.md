# ゲームデザイン

## 現状（2026-11-07 時点の実装）

クリエイティブモードのみのボクセルサンドボックス。シード付きの無限ワールドを歩き、飛び、ブロックを置いて壊す。

- ワールド: 16×16×256 のチャンク、海面 y=62、バイオーム・洞窟・鉱石・木・水。
- ブロック: 約160種（`wc.h` の `WC_BLOCK_LIST`）。インベントリ画面に 72 枠、ホットバー 9 枠。
- 時間と天候: 昼夜サイクル（T で早送り、Shift+T で巻き戻し）、雨、雷。
- 演出: 破壊パーティクル、ホタル、手に持ったブロック、手続き生成の効果音。
- 保存: なし（リロードで編集内容は消える。BUG_TRACKER 参照）。

## 操作

| 入力 | 動作 |
|---|---|
| W A S D | 移動（W の2回押しか Ctrl でダッシュ） |
| Space | ジャンプ（2回押しか F で飛行） |
| Shift | スニーク / 下降 |
| 左 / 右クリック | 破壊 / 設置 |
| 中クリック | ブロックを拾う |
| 1–9 / ホイール | ホットバー選択 |
| E | インベントリ |
| T（長押し） | 時間早送り、Shift+T で巻き戻し |
| F1 / F2 / F3 | HUD 非表示 / スクリーンショット / デバッグ情報 |
| Esc | メニューと設定 |
| タッチ | 左スティック移動、ドラッグで視点、タップで設置、長押しで破壊 |

## 未定（Phase 1 で決める）

- 1プレイの長さ、対象デバイス（PC とモバイルのどちらを優先するか）。
- マネタイズの有無。
